## 🌐 Deploy to GitHub Pages

To deploy this portfolio to GitHub Pages:

### 1. Initialize Git and commit your files

```bash
git init
git add .
git commit -m "Initial commit: Rohan Marri developer portfolio"
```

### 2. Add your remote repository and push

```bash
git branch -M main
git remote add origin https://github.com/MarriRohan/Rohan-Portfolio.git
git push -u origin main
```

*(If you already have a repository, ensure your remote URL points to `https://github.com/MarriRohan/Rohan-Portfolio.git`)*

### 3. Enable GitHub Pages

1. Navigate to your repository on GitHub: `https://github.com/MarriRohan/Rohan-Portfolio`
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select the **main** branch and **/ (root)** folder.
5. Click **Save**.
6. Within 1-2 minutes, your portfolio will be live at:
   👉 **https://marrirohan.github.io/Rohan-Portfolio/**
